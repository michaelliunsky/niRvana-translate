# Plugin Basic Features

- **Multi-language Support** - Implements real-time webpage translation based on translate.js, supporting multiple language switching.
- **Visual Configuration** - Provides a WordPress backend settings interface for easily adding and managing language options.
- **Flexible Script Loading** - Supports loading translate.js locally or from a remote CDN, with automatic fallback to local loading if remote loading fails.
- **Menu Integration** - Allows one-click addition of the translation function to the website navigation menu for easy user access.
- **Custom Display** - Supports custom menu button names and language display names.
- **Icon Support** - Icons can be configured for each language to enhance the user experience.

# Installation

Environment Requirement: **Best compatible with PHP8.3**

Download the .zip file from the [Release](https://github.com/michaelliunsky/niRvana-translate/releases) page, then upload and install it via the "Plugins" page in the WordPress backend.

# Usage Guide

1.  Add languages in the "Translation Language Settings" and save.
2.  Choose the translate.js loading method: Local (built-in with the plugin) or Remote (custom URL, provides fallback to local loading if remote loading fails).
3.  Go to 【Appearance → Menus】 → niRvana Translate Menu on the left → Check and "Add to Menu".
