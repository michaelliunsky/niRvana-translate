# Features

- Add languages via the admin panel (name, code, icon)
- Customize the menu button label
- Add the language switcher to your navigation menu
- Built-in translate.js support

# Installation

**Requires PHP 8.3 or later for best compatibility.**

Download the .zip file from the [Releases](https://github.com/michaelliunsky/niRvana-translate/releases) page, then upload and install it on the **Plugins** page in your WordPress admin.

# Getting Started

1. Go to **Translation Language Settings** and add the languages you need, then save.
2. Navigate to **Appearance → Menus**, find the **niRvana Translate Menu** block on the left, check the items you want, and click **Add to Menu**.
