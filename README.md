# 功能

- 后台添加语言（名称、简码、图标）
- 自定义菜单按钮名称
- 添加到导航菜单
- 内置 translate.js

# 安装

环境要求：**PHP8.3 兼容最佳**

在 [Release](https://github.com/michaelliunsky/niRvana-translate/releases) 页面下载 .zip 文件，在 WordPress 后台 "插件" 页面上传并安装。

# 使用引导

1. 在“翻译语言设置”添加语言并保存。
2. 到【外观 → 菜单】→ 左侧 niRvana 翻译菜单 → 勾选并“添加到菜单”。
