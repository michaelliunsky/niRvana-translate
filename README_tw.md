# 功能

- 後台新增語言（名稱、簡碼、圖示）
- 自訂選單按鈕名稱
- 新增至導覽選單
- 內建 translate.js

# 安裝

環境需求：**PHP8.3 相容性最佳**

在 [Release](https://github.com/michaelliunsky/niRvana-translate/releases) 頁面下載 .zip 檔案，在 WordPress 後台「外掛」頁面上傳並安裝。

# 使用引導

1. 在「翻譯語言設定」中新增語言並儲存。
2. 前往【外觀 → 選單】→ 左側 niRvana 翻譯選單 → 勾選並「新增至選單」。
