# 外掛基本特性

- **多語言支援** - 基於 translate.js 實現網頁即時翻譯，支援多種語言切換
- **可視化配置** - 提供 WordPress 後台設定介面，可輕鬆新增和管理語言選項
- **靈活的腳本載入** - 支援本地或遠端 CDN 載入 translate.js，遠端載入失敗時自動回退到本地
- **選單整合** - 可將翻譯功能一鍵新增到網站導航選單中，方便使用者存取
- **自訂顯示** - 支援自訂選單按鈕名稱和語言顯示名稱
- **圖示支援** - 可為每種語言配置圖示，提升使用者體驗

# 安裝

環境要求：**PHP8.3 相容最佳**

在 [Release](https://github.com/michaelliunsky/niRvana-translate/releases) 頁面下載 .zip 文件，在 WordPress 後台 "外掛" 頁面上傳並安裝。

# 使用引導

1. 在“翻譯語言設定”新增語言並儲存。
2. 選擇 translate.js 引入方式：本地（外掛內建）或遠端（自訂 URL，提供遠端載入失敗回退本地）。
3. 到【外觀 → 選單】→ 左側 niRvana 翻譯選單 → 勾選並“新增到選單”。
